# Example: two direct dependencies

The simplest dependency result: a contract that was observed to invoke two others. Two
edges, each with a basis, evidence and a confidence level.

## The command

```console
cargo run -q -p amasario-cli -- export \
  --input fixtures/graphs/direct.json \
  --format dot
```

This runs offline. `fixtures/graphs/direct.json` is a graph document in the
specification's shape, generated by the engine from the corpus's recorded invocations,
so the example can be committed and checked rather than described.

## What the output shows

Three nodes and two edges. Every edge carries its own evidence and confidence rather than
the graph carrying a summary of them:

```
"CONTRACT:CCQ2..." -> "CONTRACT:CCZL..." [
  label="INVOCATES\nVERIFIED",
  amasarioEdge="71ee1a32...",
  amasarioObserved="true",
  amasarioConfidence="VERIFIED",
  amasarioEvidence="0101...",
  amasarioBoundary="testnet@ledger1044"
];
```

Four of those attributes are the point:

- `amasarioObserved="true"` records that the edge was **observed** rather than inferred.
  An inferred edge would be `false` and would have to carry the basis it was inferred
  from.
- `amasarioEvidence` names the transaction the invocation was read out of. An edge with
  no evidence is unrepresentable, so there is no way to publish one.
- `amasarioConfidence` is the level the evidence supports, which for an observed
  invocation is a ceiling of `VERIFIED`.
- `amasarioBoundary` is where the observation was made. The same two contracts at a
  later ledger may not be a dependency at all, and two edges observed at different
  boundaries are not the same edge.

## What this is not

Two contracts that mention each other, share a name, or appear in the same repository are
not dependencies. A dependency requires an observation: an invocation in a transaction,
or a cross-contract call in an event. The engine will not establish an edge from any
weaker signal, and a candidate it refuses is published as an `unresolved` entry rather
than dropped, so a refusal is visible as a refusal.

## The live equivalent

The corpus document is the shape of the answer. The command that produces it against a
chain is:

```console
cargo run -q -p amasario-cli -- dependencies \
  --contract CCQ2DINBUGQ2DINBUGQ2DINBUGQ2DINBUGQ2DINBUGQ2DINBUGQ2CNSG \
  --network testnet --depth 1
```

`--depth 1` bounds the search to direct edges. Without `--scan-events` the engine reads
invocations from operations and transactions; cross-contract calls that only appear as
events need `--scan-events`, and the result says which of the two it saw.
